# 📝 Modern React Todo App

A feature-rich, clean, and responsive Todo Application built with **React**, **Tailwind CSS**, and **LocalStorage** for data persistence.

## 🚀 Features

- **CRUD Operations**: Add, read, and delete tasks easily.
- **Task Filtering**: Filter tasks by *All*, *Active*, *Completed*, and *Favorites*.
- **Persistence**: Your tasks are saved in the browser's `localStorage` using a **Custom React Hook**.
- **Favorites System**: Mark important tasks as favorites with a single click.
- **Responsive Design**: Fully responsive UI styled with Tailwind CSS.
- **Clean Architecture**: Organized folder structure with reusable components and custom hooks.

## 🛠️ Tech Stack

- **Framework**: [React.js](https://reactjs.org/) (Vite)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
- **State Management**: React Hooks (`useState`, `useEffect`)
- **Persistence**: Custom `useLocalStorage` hook
